# 辨识

本页说明 `rebot_control.calib` 背后的数学，以及每种方法在什么情况下失效。

## 静态重力模型

刚体动力学对动力学参数是线性的：`tau = Y(q, dq, ddq) pi`，每个刚体 10 个参数
（`RobotModel.regressor`，Pinocchio 的 `computeJointTorqueRegressor`）。静止时只剩重力项，而重力项只依赖
`m` 和 `m c`（每个刚体 4 个参数）。对应的列由 `static_columns(n)` 给出。

**可辨识性。** 6 个刚体共有 24 个静态参数，但这台机械臂的静态回归矩阵秩只有 10（打印为 `regressor_rank`）。
原因有两个：

- 关节 1 是竖直的，重力从不对它加载，所以连杆 1 的参数完全看不到；
- 对其余刚体，起作用的只是参数的某些组合（即“基参数”）。

普通最小二乘会在零空间里填上任意的值。

**MAP 拟合**（`fit_gravity`）。它最小化

```
|| (Y theta + B b - tau) / s_tau ||^2 + || (theta - theta0) / s_theta ||^2 + || b / s_b ||^2
```

其中：

- `theta0` 是先验（URDF 或上一次的标定结果，负载计入法兰所在的刚体）；
- `s_theta` 对质量取 `prior_rel * m0 + prior_abs`，对一阶矩再乘以 `lever_m`；
- `b` 是每个关节的力矩偏置，先验为 `s_b`；
- `s_tau` 是力矩噪声。

数据能约束的方向跟着数据走，其余方向留在先验上。结果以每个连杆的质量加质心给出（质心 = `m c / m`；
如果 `m` 算出来不符合物理，就保留先验，并记一条警告日志）。

**静止时的摩擦。** 静止的关节可以承受静摩擦带内的任意力矩。每个位姿都从两侧各接近一次再取平均，
可以在一阶上把它抵消掉。剩下的离散程度体现在残差 RMS 里。

**负载**（`fit_payload`）。静态方程相同，但只有法兰所在刚体的 4 个参数可变，机械臂本体的参数固定。
只要腕部姿态有足够变化，这个问题就是良态的。质心会从关节坐标系换算到安装坐标系。

## 摩擦

关节 j 单独匀速运动时：`tau_j = rnea_j(q, dq, 0) + f(v) + e(q_j)`。其中 `e(q_j)` 是刚体模型沿扫描行程的误差，
用 `a sin q_j + b cos q_j + c` 近似。

模型为 `f(v) = fc tanh(v / vs) + fv v`，`vs` 固定为 0.02 rad/s。拟合用线性最小二乘，只取匀速段的样本：
名义速度不为零，且实测速度与它相差在 20 % 以内。名义速度在时间上按 `filter_tau_s`（关节目标滤波器的滞后）对齐。

**局限**：

- 库仑摩擦的不对称（`fc_pos != fc_neg`）无法与 `c` 同时辨识，所以拟合是对称的。
- 约 3 deg/s 以下的 Stribeck 效应没有建模。
- 与位置有关的摩擦（齿槽效应）会落进残差。

上报力矩在零阶保持周期内的采样相位会使 `fv` 产生偏差，最大为 `kp Ts / 2`
（见 [servo-and-timing.md](servo-and-timing.md)）。在真机上的检查方法：用两个不同的 kp 各辨识一次，再比较结果。

## TCP 支点标定

把 `[R_i  -I] [t; c] = -p_i` 叠起来，用最小二乘求解。如果所有 `R_i` 都很接近，问题就是病态的，
`solve_pivot` 会拒绝求解。残差 RMS 就是工具尖端的定位误差。只辨识位置，因为支点标定不含任何关于 TCP 姿态的信息。

## 增益

每个关节用二阶模型：`omega_n = sqrt(kp / J)`，`zeta = kd / (2 sqrt(kp J))`，其中
`J = M(q)_jj + rotor_inertia`。阶跃响应的各项指标和搜索过程见 [`../user/gains.md`](../user/gains.md)。
模型没有考虑延迟，所以 `zeta_est`（由超调算出）低于 `zeta_model` 说明存在未建模的滞后，高于它则说明有摩擦。

## 尚未实现的想法

- **动态辨识**（惯量、转子惯量）：用激励轨迹，配合完整的回归矩阵，`dq`、`ddq` 取自滤波后的编码器数据。
  这能改进 `rotor_inertia`，而增益的计算依赖它。
- **关节零位偏差标定**（编码器零位误差）：用外部跟踪设备测量 TCP。
- **负载惯量**：需要动态数据。
