# 路线图

## 项目现状

0.1 版就是这个仓库里现有的内容。自动化测试都在仿真里跑。真机的上机调试按
[`../user/hardware-test-plan.md`](../user/hardware-test-plan.md) 进行，尚未完成。

## 后续计划（大致按先后顺序）

1. 修复真机测试中发现的问题。把本库的增益和安全默认值定下来。
2. 面向推动实验的阻抗 / 导纳模式：降低关节 kp，用 `J^T K (x* - x)` 前馈实现笛卡尔刚度；
   再结合辨识得到的重力和摩擦，由电机力矩估计接触力。
3. 动态辨识（惯量、转子惯量）和关节零位偏差标定。
4. 给力矩波动标定加一个 CLI 命令。
5. 如果 Python 线程的时序不够好，提供可选的独立伺服进程（共享内存）。
6. B601-DM（达妙电机）后端。
7. ROS 2 封装（`ros2_control` 硬件接口或一个轻量节点），作为单独的包。
