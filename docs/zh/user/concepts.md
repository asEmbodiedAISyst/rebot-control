# 基本概念

本页解释其他页面用到的术语。

## 控制链路

你的代码按控制频率（30 Hz）下发目标。库把这些目标转换成伺服频率（150 Hz）的电机指令。

```
your loop (30 Hz)  ->  joint target filter  ->  servo loop (150 Hz)  ->  motors (MIT mode)
 joint or TCP target    limits, smoothing        interpolation, feedforward
```

- **关节目标**是每个关节一个角度。**TCP 目标**是工具末端的位姿。笛卡尔控制器用逆运动学（IK）把 TCP 目标换算成关节目标。
- **关节目标滤波器**对每个关节目标做限幅、限速和平滑，然后才交给机械臂。
- **伺服循环**在相邻目标之间插值，并加上前馈力矩。
- 在 **MIT 模式**下，每个电机驱动器按收到的最后一帧执行 PD 控制律：
  `tau = kp (q* - q) + kd (dq* - dq) + tau_ff`。见 [MIT 增益](gains.md)。

## 后端

后端把控制代码接到一台机械臂上。后端有两种：

- `real`：SocketCAN 上的 RobStride 电机。需要 Linux 和 `real` extra。
- `sim`：同一台机械臂的 MuJoCo 模型。任何操作系统都能运行，需要 `sim` extra。

两种后端用的是同一套控制代码。在仿真里能跑的脚本，把 `backend="sim"` 改成 `backend="real"` 就能在真机上跑。

## 模式

| 模式 | 力矩 | 机械臂的表现 |
| --- | --- | --- |
| `PASSIVE` | 关 | 不出力。机械臂处于卸力状态，没有支撑就会掉下来。 |
| `HOLD` | 开 | 用 PD 控制律和重力前馈跟随关节目标。 |
| `GRAVITY` | 开 | `kp = 0`，只有重力（和摩擦）前馈。可以用手拖动机械臂。 |

## 位姿

- **折叠位姿**（零位）是停放时的位姿，所有关节都在 0。机械臂从这里开始，也在这里结束。
- **home 位姿**由工具决定，是 `arm.move_home()` 要去的工作位姿。
- 机械臂**分阶段**展开和折叠，这样腕部不会蹭到大臂。

## 工具

一个工具就是一个 YAML 文件。它告诉库：

- **TCP**（工具中心点）：工具末端在法兰坐标系下的位姿；
- **负载**：工具的质量和质心，重力前馈要用到；
- home 位姿和默认的笛卡尔限制。

**法兰**是机械臂的最后一个连杆（`link6`），工具装在它上面。

## 前馈和标定

**前馈**是模型算出的、机械臂需要的力矩：重力是基本项，摩擦和力矩波动可以按需加上。模型准的话，PD 控制律只需要修正很小的误差。

**标定**在你的机械臂上把模型测出来：连杆质量、工具负载、摩擦和 TCP 位置。结果写入标定文件，一份标定文件只对应一台机械臂。
见[标定](calibration.md)。

## 程序结束时

- 正常结束时，机械臂先折叠，再卸力。
- 出错或按下 Ctrl-C 之后，机械臂**保持当前位姿，并且一直使能**。下一个程序会接管这个保持状态。要结束它，用
  `rebot-control release`。

原因和风险见[安全](safety.md)。
