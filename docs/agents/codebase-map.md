# Codebase map

```
src/rebot_control/
  __init__.py          public API exports
  arm.py               Arm facade: from_config, connect/enable/close, command_joint, move_*, cartesian(),
                       gravity_mode/hold, check_stall, sleep/wait, set_tool, recording
  cartesian.py         CartesianLimits (from tool YAML), CartesianController.step / hold / reachable
  servo.py             ServoLoop (PASSIVE / HOLD / GRAVITY), tick(), feedforward(), thread, recording
  joint_filter.py      JointTargetFilter: clip -> jump guard -> rate limit -> low-pass
  ik.py                DiffIK (DLS + posture null space), IKResult
  model.py             RobotModel (Pinocchio): fk, jacobian, gravity, mass_matrix, regressor, set_tool, set_link_params
  pose.py              rotation helpers, tilt / yaw limits, pose deltas, rot6d
  config.py            ArmConfig, ToolConfig, Calibration, FrictionParams (YAML <-> dataclasses, deg -> rad)
  errors.py            RebotControlError, CommandRejected, SafetyStop, BackendError
  cli.py               rebot-control: state, release, hold, float, home, square,
                       calib {gravity,payload,friction,tcp,gains}
  backends/base.py     Backend ABC, JointState
  backends/robstride.py  motorbridge / SocketCAN backend, check_can_up
  backends/sim.py      MuJoCo backend (build_mjspec from the Pinocchio model; truth_* overrides; viewer)
  calib/poses.py       clearance check (table, base column), random clear pose tours
  calib/gravity.py     collect_static, fit_gravity (MAP), fit_payload
  calib/friction.py    sweep trajectories, collect_sweeps, fit_joint_friction
  calib/tcp.py         solve_pivot, collect_pivot (interactive)
  calib/gains.py       step_response, analyze_step, find_kp_max
  configs/arms/b601_rs.yaml       hardware, gains, safety, poses, sim
  configs/tools/*.yaml            none, pusher_ip17, stock_gripper
  assets/b601_rs/                 arm-only URDF (generated by tools/make_arm_urdf.py) + CERN-OHL-W licence
tests/test_core.py     model-only tests
tests/test_sim.py      closed-loop simulator tests (identification recovers truth)
examples/              one script per feature, all with --sim
tools/make_arm_urdf.py regenerates the URDF from Seeed's upstream file
docs/                  English pages in user/, developer/, agents/; Chinese pages in zh/; build.py builds the site
```

## Call path of one Cartesian step

`CartesianController.step` -> `Arm.check`, `Arm.lag`, `Arm.check_stall` -> `CartesianController.limit` ->
`DiffIK.solve` -> `Arm.command_joint` -> `JointTargetFilter.__call__` -> `ServoLoop.set_target`. Later, on each
servo tick: `ServoLoop.tick` -> `Backend.read`, `_check_temperature`, interpolation / cap / `feedforward` ->
`Backend.send_mit`.
